# Data README

## Overview

This project uses public Divvy trip data to compare bike-share behavior between annual members and casual riders.

## Processed Data

Processed files are stored in `data/processed/` and are small enough to track.

Generated by `notebooks/02_data_cleaning.ipynb` or `python scripts/clean_data.py`:

- `overall_summary.csv`: annual ride counts and ride-duration metrics by rider type
- `rides_by_month.csv`: monthly ride counts and average duration by rider type
- `rides_by_weekday.csv`: weekday ride counts and average duration by rider type
- `rides_by_hour.csv`: hourly ride counts and average duration by rider type
- `rides_by_bike_type.csv`: bike type mix by rider type
- `top_start_stations.csv`: top start stations by rider type, excluding blank station names
- `data_quality_summary.csv`: row counts and cleaning outcomes by source file
- `behavior_flags_summary.csv`: monthly counts and shares for weekend, commute-window, and round-trip flags
- `rides_by_weekday_hour.csv`: weekday-hour ride counts used for heatmaps
- `key_metrics.json`: machine-readable analysis window, cleaning rules, created columns, and summary totals

- `data_quality_totals.csv`

## Known Limitations

- The public data is anonymized.
- The data does not include demographics, customer IDs, purchase history, campaign exposure, or conversion outcomes.
- Some rides have missing start or end station names.
- The processed files are aggregated; this repository does not store a row-level cleaned dataset to keep the project GitHub-friendly.
- Charts are displayed inline in `notebooks/03_exploratory_analysis.ipynb` and saved as image files in `reports/figures/`.
